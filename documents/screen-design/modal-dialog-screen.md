# モーダル・ダイアログ画面設計書

## 概要

Pointlessアプリケーションで使用される各種モーダルダイアログの設計仕様です。モーダルは共通のModalコンポーネントをベースに、エクスポート設定、ヘルプ情報、ペーパー情報、設定画面などの機能を提供します。

## 共通モーダルコンポーネント（Modal Component）

### 基本構造
```
┌─────────────────────────────────────┐
│ ┌─────────────────────────────────┐ │
│ │ タイトル                    [×] │ │
│ ├─────────────────────────────────┤ │
│ │                                 │ │
│ │         コンテンツエリア        │ │
│ │                                 │ │
│ ├─────────────────────────────────┤ │
│ │          アクションエリア       │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

### 仕様
- **サイズ**: small（デフォルト）、medium
- **オーバーレイ**: 半透明の背景でモーダル以外の操作を無効化
- **閉じる機能**: 右上の×ボタンまたはESCキー
- **レスポンシブ**: ビューポートサイズに応じて幅を自動調整

### アニメーション
- **開く時**: フェードイン + 上からスライドイン
- **閉じる時**: フェードアウト + 下へスライドアウト
- **所要時間**: 200ms

## 1. エクスポートダイアログ（ExportButton Component）

### 機能
描画内容を画像ファイルとして保存

### UI要素

#### 保存場所
- **ラベル**: "Location"
- **値**: ダウンロードディレクトリのパス（読み取り専用）
- **表示**: 省略記号付きで長いパスを処理

#### ファイル名
- **ラベル**: "Filename" または "Filename (edited)"
- **入力**: インライン編集可能
- **拡張子**: 自動付与（選択された形式に応じて）
- **revertボタン**: 編集時のみ表示、元の名前に戻す

#### テーマ選択（SVG以外）
- **ラベル**: "Theme"
- **選択肢**: 
  - dark: ダークテーマでエクスポート
  - light: ライトテーマでエクスポート

#### ファイル形式
- **ラベル**: "Type"
- **選択肢**:
  - JPEG: 標準的な画像形式
  - PNG: 透過対応
  - SVG: ベクター形式

#### 透過背景オプション（PNGのみ）
- **チェックボックス**: "Transparent background"
- **デフォルト**: オフ

#### アクション
- **Exportボタン**: プライマリボタン、エクスポート実行

### バリデーション
- ファイル名の無効文字チェック
- 空のキャンバス時はエクスポートボタンを無効化

## 2. ヘルプダイアログ（HelpButton Component）

### 機能
キーボードショートカット一覧の表示

### UI要素
- **サイズ**: medium
- **内容**: テーブル形式のショートカット一覧

### ショートカット一覧

| キー | 説明 |
|------|------|
| F | フリーハンド描画 |
| E | 楕円描画 |
| R | 矩形描画 |
| A | 矢印描画 |
| Space | パンモード（押している間） |
| Ctrl/Cmd + E | 消しゴム |
| Ctrl/Cmd + X | キャンバスクリア |
| Ctrl/Cmd + Z | 元に戻す |
| Ctrl/Cmd + Shift + Z | やり直し |
| Ctrl/Cmd + + | ズームイン |
| Ctrl/Cmd + - | ズームアウト |
| Ctrl/Cmd + 0 | ズームリセット |
| ] | 消しゴムサイズ拡大 |
| [ | 消しゴムサイズ縮小 |
| Ctrl/Cmd + C | 選択シェイプをコピー |
| Ctrl/Cmd + V | 選択シェイプを貼り付け |
| Delete/Backspace | 選択シェイプを削除 |
| Shift | アスペクト比保持（描画中） |
| Ctrl/Cmd + Q | アプリケーション終了 |

### プラットフォーム対応
- Windows/Linux: Ctrlキー表示
- macOS: Cmdキー表示

## 3. ペーパー情報ダイアログ（InfoButton Component）

### 機能
現在開いているペーパーとフォルダの情報表示・編集

### UI要素

#### ペーパー名
- **ラベル**: "Name"
- **入力**: インライン編集可能
- **保存**: フォーカスアウトまたはEnterキーで自動保存

#### フォルダ名
- **ラベル**: "Folder"
- **入力**: インライン編集可能
- **効果**: 所属フォルダ名の変更（フォルダ移動ではない）

#### 最終更新日時
- **ラベル**: "Last modified"
- **表示**: 相対時間表示（例: "2 hours ago"）
- **ツールチップ**: 完全な日時表示

#### 作成日時
- **ラベル**: "Created"
- **表示**: 相対時間表示
- **ツールチップ**: 完全な日時表示

## 4. 設定画面（ToggleDarkMode Component）

### 機能
アプリケーション全体のテーマ切り替え

### UI要素
- **トグルスイッチ**: ライト/ダークモード切り替え
- **アイコン**: 太陽（ライト）/月（ダーク）
- **アニメーション**: スムーズなスライド切り替え

### 動作
- 即座に全画面に適用
- 設定は永続化され次回起動時に復元

## 共通仕様

### アクセシビリティ
- **キーボード操作**:
  - Tab: フォーカス移動
  - Enter: ボタン押下・選択確定
  - Escape: モーダルを閉じる
- **フォーカス管理**: モーダル内でフォーカストラップ
- **ARIAラベル**: 適切なrole属性とaria-label

### エラーハンドリング
- **ファイル保存エラー**: エラーメッセージ表示
- **無効な入力**: リアルタイムバリデーション
- **API エラー**: 適切なフォールバック

### パフォーマンス
- **遅延読み込み**: 必要時のみコンポーネント読み込み
- **メモ化**: React.memoによる不要な再レンダリング防止

### テーマ対応

#### ライトモード
- 背景: 白
- テキスト: ダークグレー
- ボーダー: 薄いグレー
- オーバーレイ: 半透明黒

#### ダークモード
- 背景: ダークグレー
- テキスト: 明るいグレー  
- ボーダー: 暗いグレー
- オーバーレイ: より濃い半透明黒

## 確認ダイアログ（Tauri Dialog API）

### 用途
- フォルダ削除確認
- ペーパー削除確認
- キャンバスクリア確認

### 仕様
- **ネイティブダイアログ**: OS標準のダイアログ使用
- **ボタン**: OK/キャンセル
- **メッセージ**: 削除対象を明確に表示
