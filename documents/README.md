# Pointless アプリケーション設計書

このディレクトリには、Pointlessアプリケーションの包括的な設計書が含まれています。

## ディレクトリ構成

- **screen-design/** - 画面設計書
  - 各画面の構成要素とレイアウト
  - UI要素の配置と機能
  - レスポンシブデザインとテーマ対応

- **screen-flow/** - 画面遷移図
  - 画面間の遷移フロー
  - ナビゲーションパス
  - モーダル・オーバーレイの遷移

- **data-model/** - データモデル設計書
  - データ構造の定義
  - データモデル間の関係性
  - ローカルストレージ仕様

- **architecture/** - ソフトウェアアーキテクチャ設計書
  - システム全体構成
  - コンポーネント階層
  - 状態管理とデータフロー

- **interface/** - インタフェース仕様書
  - Tauri API仕様
  - コンポーネント間インタフェース
  - 外部ライブラリ連携

- **requirements/** - 要求定義書
  - 機能要求の体系化
  - 非機能要求の定義
  - 将来拡張要求

- **consistency-analysis/** - 整合性分析
  - 設計書間の整合性分析
  - 修正記録とサマリー

## 設計書の読み方

1. まず「要求定義書」で全体的な要求事項を確認
2. 「アーキテクチャ設計書」でシステム全体像を把握
3. 「画面設計書」と「画面遷移図」でUI/UXを理解
4. 「データモデル設計書」でデータ構造を確認
5. 「インタフェース仕様書」で詳細な実装仕様を参照
