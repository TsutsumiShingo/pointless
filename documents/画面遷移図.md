# 画面遷移図

## 1. 概要

Pointlessアプリケーションの画面遷移は、ライブラリ画面と描画画面を中心としたシンプルな構成になっています。各画面間の遷移とモーダルダイアログの表示フローを定義します。

## 2. 画面遷移図

```mermaid
stateDiagram-v2
    [*] --> ライブラリ画面
    
    ライブラリ画面 --> 描画画面 : ペーパー選択
    描画画面 --> ライブラリ画面 : 戻るボタン
    
    ライブラリ画面 --> フォルダ作成モーダル : 新規フォルダボタン
    フォルダ作成モーダル --> ライブラリ画面 : 作成/キャンセル
    
    ライブラリ画面 --> ペーパー作成モーダル : 新規ペーパーボタン
    ペーパー作成モーダル --> ライブラリ画面 : 作成/キャンセル
    
    ライブラリ画面 --> 削除確認モーダル : 削除ボタン
    削除確認モーダル --> ライブラリ画面 : 削除/キャンセル
    
    描画画面 --> エクスポートモーダル : エクスポートボタン
    エクスポートモーダル --> 描画画面 : エクスポート/キャンセル
    
    描画画面 --> ヘルプモーダル : ヘルプボタン
    ヘルプモーダル --> 描画画面 : 閉じる
    
    描画画面 --> 情報モーダル : 情報ボタン
    情報モーダル --> 描画画面 : 閉じる
    
    ライブラリ画面 --> ライブラリ画面 : フォルダ選択

    ライブラリ画面 --> ライブラリ画面 : ソート変更
    ライブラリ画面 --> ライブラリ画面 : ダークモード切替
    
    描画画面 --> 描画画面 : 描画操作
    描画画面 --> 描画画面 : ツール変更
    描画画面 --> 描画画面 : ズーム/パン
    描画画面 --> 描画画面 : ダークモード切替
```

## 3. 詳細遷移フロー

### 3.1 ライブラリ画面の遷移

```mermaid
flowchart TD
    A[ライブラリ画面] --> B{ユーザーアクション}
    
    B -->|ペーパー選択| C[描画画面]
    B -->|新規フォルダ| D[フォルダ作成モーダル]
    B -->|新規ペーパー| E[ペーパー作成モーダル]
    B -->|削除ボタン| F[削除確認モーダル]
    B -->|フォルダ選択| G[ライブラリ画面更新]
    B -->|表示モード切替| H[ライブラリ画面更新]
    B -->|ソート変更| I[ライブラリ画面更新]
    B -->|ダークモード切替| J[ライブラリ画面更新]
    
    D --> K{モーダル操作}
    E --> K
    F --> K
    
    K -->|作成/削除| L[Redux状態更新]
    K -->|キャンセル| M[モーダル閉じる]
    
    L --> N[ファイルシステム操作]
    N --> O[ライブラリ画面更新]
    M --> P[ライブラリ画面]
    G --> P
    H --> P
    I --> P
    J --> P
    
    C --> Q[描画画面]
```

## 6. ユーザー操作フロー

### 6.1 新規ペーパー作成フロー

```mermaid
sequenceDiagram
    participant U as ユーザー
    participant L as ライブラリ画面
    participant R as Redux
    participant T as Tauri
    participant F as ファイルシステム
    
    U->>L: 新規ペーパーボタンクリック
    L->>L: ペーパー作成モーダル表示
    U->>L: ペーパー名入力
    U->>L: 作成ボタンクリック
    L->>R: newPaperInFolderアクション
    R->>T: ファイル作成命令
    T->>F: ペーパーファイル作成
    F-->>T: 作成完了
    T-->>R: 成功通知
    R-->>L: 状態更新
    L->>L: モーダル閉じる
    L->>L: ペーパー一覧更新
```

### 6.2 描画操作フロー

```mermaid
sequenceDiagram
    participant U as ユーザー
    participant P as 描画画面
    participant C as キャンバス
    participant R as Redux
    participant T as Tauri
    participant F as ファイルシステム
    
    U->>P: 描画操作開始
    P->>C: マウス/タッチイベント
    C->>P: 座標計算
    P->>P: 図形生成
    P->>R: 状態更新
    R->>C: 描画更新
    C-->>P: 描画完了
    P->>T: 自動保存
    T->>F: ファイル保存
    F-->>T: 保存完了
    T-->>P: 保存成功通知
```

## 7. パフォーマンス考慮事項

### 7.1 遷移最適化

- **遅延読み込み**: 必要な時点でのデータ読み込み
- **状態キャッシュ**: 頻繁にアクセスする状態のキャッシュ
- **非同期処理**: 重い処理の非同期実行

### 7.2 ユーザー体験

- **即座のフィードバック**: 操作に対する即座の視覚的フィードバック
- **プログレス表示**: 長時間処理の進行状況表示
- **エラー回復**: エラーからの自動回復機能
