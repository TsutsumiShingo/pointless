# 要求定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名

Pointless - エンドレス描画キャンバスアプリケーション

### 1.2 プロジェクトの目的

シンプルなホワイトボード/ノートアプリとして使用できる、エンドレス描画キャンバスを提供する。

### 1.3 技術スタック

- **フロントエンド**: React 18.2.0
- **バックエンド**: Tauri (Rust)
- **状態管理**: Redux Toolkit
- **描画技術**: SVG キャンバス
- **ファイル圧縮**: brotli-unicode
- **UIライブラリ**: カスタムコンポーネント

## 2. 機能要求

### 2.1 基本機能

#### 2.1.1 描画機能

- **自由描画**: マウス/タッチで自由に線を描画できる
- **図形描画**: 矩形、楕円、矢印の描画が可能
- **選択機能**: 描画された図形を選択・移動・編集できる
- **消しゴム機能**: 描画内容を消去できる

#### 2.1.2 ファイル管理機能

- **フォルダ作成**: プロジェクトを整理するためのフォルダを作成できる
- **ペーパー作成**: フォルダ内に新しい描画ペーパーを作成できる
- **名前編集**: フォルダ名・ペーパー名を編集できる
- **削除機能**: フォルダ・ペーパーを削除できる

#### 2.1.3 エクスポート機能

- **PNG形式**: 画像としてPNG形式でエクスポート
- **JPEG形式**: 画像としてJPEG形式でエクスポート
- **SVG形式**: ベクター形式でSVG形式でエクスポート

#### 2.1.4 表示・操作機能

- **ズーム機能**: キャンバスの拡大・縮小が可能
- **パン機能**: キャンバスを移動できる
- **フィット表示**: 描画内容に合わせて自動調整
- **アンドゥ・リドゥ**: 操作の取り消し・やり直しが可能
- **クリア機能**: キャンバス全体をクリアできる

### 2.2 ユーザーインターフェース要求

#### 2.2.1 テーマ機能

- **ライトモード**: 明るいテーマでの表示
- **ダークモード**: 暗いテーマでの表示
- **自動切り替え**: システム設定に応じた自動切り替え

#### 2.2.2 表示モード

- **グリッド表示**: ペーパーをグリッド形式で表示
- **リスト表示**: ペーパーをリスト形式で表示
- **ソート機能**: 名前、作成日時、更新日時でソート

#### 2.2.3 レスポンシブ対応

- **デスクトップ対応**: マウス・キーボード操作
- **タッチ対応**: タッチデバイスでの操作

### 2.3 データ管理要求

#### 2.3.1 ローカル保存

- **自動保存**: 変更内容の自動保存
- **圧縮保存**: brotli-unicodeによるファイル圧縮
- **設定保存**: ユーザー設定の永続化

#### 2.3.2 データ構造

- **フォルダ階層**: フォルダ内にペーパーを格納
- **メタデータ管理**: 作成日時、更新日時、名前などの管理

## 3. 非機能要求

### 3.1 性能要求

- **起動時間**: 3秒以内でのアプリケーション起動
- **描画レスポンス**: 描画操作の即座な反映
- **ファイルサイズ**: 効率的な圧縮による小さいファイルサイズ

### 3.2 可用性要求

- **安定性**: クラッシュのない安定した動作
- **データ保護**: データの損失を防ぐ仕組み
- **エラーハンドリング**: 適切なエラー処理とユーザーへの通知

### 3.3 互換性要求

- **クロスプラットフォーム**: Windows, macOS, Linux対応
- **デバイス対応**: デスクトップ・タブレット対応
- **ブラウザ非依存**: スタンドアロンアプリケーション

### 3.4 セキュリティ要求

- **ローカル保存**: インターネット接続不要のローカル保存
- **データプライバシー**: 外部へのデータ送信なし

## 4. 制約事項

### 4.1 技術制約

- **Tauriフレームワーク**: Rust + Web技術の組み合わせ
- **SVG描画**: ベクター形式での描画実装
- **ローカルファイルシステム**: ファイルシステムへの直接アクセス

### 4.2 運用制約

- **オープンソース**: GPL-3.0ライセンスでの公開
- **コミュニティ開発**: GitHubでの開発・管理

## 5. 成功基準

### 5.1 機能基準

- すべての基本描画機能が正常に動作すること
- ファイル管理機能が適切に動作すること
- エクスポート機能が正常に動作すること

### 5.2 品質基準

- クラッシュのない安定した動作
- 直感的で使いやすいユーザーインターフェース
- 適切なパフォーマンスでの動作

### 5.3 ユーザビリティ基準

- 初回使用でも直感的に操作できること
- 必要な機能に素早くアクセスできること
- 適切なフィードバックが提供されること
